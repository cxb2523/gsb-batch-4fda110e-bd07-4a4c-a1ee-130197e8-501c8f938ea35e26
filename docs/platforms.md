# 各平台能拿到什么

**这张表的来历：** 以下是作者在自己电脑上、2026 年 10 月 16 日到 11 月 5 日之间实际用出来的情况。整理成开源版时，没有再逐个平台付费重测；搜索结果的读取用这段时间的真实返回离线回放验证过。平台和 TikHub 的接口都会变，价格也可能调整，以你自己运行 `sourceboard doctor` 和实际搜索的结果为准。某个平台坏了，命令输出和看板会明说。

价格单位是美元，每次调用。“免费”指不调用 TikHub。

## 一、按关键词搜（`sourceboard search`）

| 微博 | 帖子、作者、转发、评论、点赞 | TikHub | $0.001 | 结果里夹的推广会被去掉 |

Instagram、Threads、LinkedIn、视频号等不支持按关键词搜，只能给链接抓。

## 三、账号主页（`sourceboard grab 主页链接`）

| 平台 | 能拿到什么 | 大概花费 | 要知道的 |
|---|---|---|---|
| 抖音 | 昵称、简介、粉丝、关注、获赞、作品数、最近一页作品 | $0.002 | 各作品的播放量默认不逐条补，`--profile-views` 才补 |
| 小红书 | 同上 | $0.02 | |
| B站 | 同上 | $0.002–0.004 | |
| TikTok | 同上 | $0.002 | |
| Instagram | 同上 | $0.004 | |
| X | 资料和最近一页帖子 | $0.002 | 不是全部历史 |
| YouTube | 频道资料、订阅数、最近上传及其播放 | 免费 | 需要配 YouTube 官方钥匙 |

`--profile-pages N` 多翻几页作品，每页再收一次钱。

## 四、拿不到的

- 任何账号的后台数据（完播率、点击率、流量来源、粉丝画像）。
- 私密、已删除、仅粉丝可见、付费的内容。
- 公众号阅读量、在看数。
- 需要登录才能看的评论和内容。
- 视频里说了什么（没有现成字幕时）。本工具不做语音转文字。
